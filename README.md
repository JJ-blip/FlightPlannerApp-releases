# FlightPlanner

Windows releases of FlightPlanner — ridge and thermal route planning for glider tasks in
Microsoft Flight Simulator 2024.

> **Not for real flying.** This is built for Microsoft Flight Simulator. Its terrain,
> weather and lift are the simulator's, not the real world's, so nothing here should be
> used to plan or fly a real flight.

FlightPlanner takes a glider ridge task — typically one generated by the B21 Task Planner —
and works out what it thinks is the fastest route through the terrain for the day's
weather. It looks for lift you can use: ridge lift on the windward faces, thermals where it
has to climb. It is best at choosing the *route*; treat its times as estimates. It adds
little on thermal-only tasks.

**[Download the latest release](../../releases/latest)**

This repository holds the releases and the user documentation only. The source is kept
separately.

## What you need

| | |
|---|---|
| Windows 10 (1809 or later) or Windows 11, x64 | |
| A free NASA Earthdata account | For ground heights. Without it the app opens but cannot plan. See below. |
| Microsoft Flight Simulator 2024 | Optional — only to show the glider live on the map. Planning works without it. |

Nothing else to install. The download is self-contained: it does not need the .NET runtime
or the Windows App SDK on your machine.

## Installing

1. Download `FlightPlanner-<version>-win-x64.zip` from the
   [latest release](../../releases/latest).
2. **Unblock the zip before you extract it:** right-click it → Properties → tick
   **Unblock** → OK. Windows marks downloaded files, and everything inside the zip inherits
   the mark if you skip this.
3. Extract it anywhere you can write to — your own folder, not `Program Files`.
4. Create the `.env` file described in the next section, beside `FlightPlannerApp.exe`.
5. Run `FlightPlannerApp.exe`. The app is not code-signed, so the first run brings up
   "Windows protected your PC": **More info → Run anyway**.

To update, extract the new version over the old folder, or into a new one and copy your
`.env` across. Nothing is installed and nothing is written to the registry, so removing the
folder removes the app.

## Ground heights: the Earthdata token

Terrain heights come from NASA's SRTM 1-arc-second elevation tiles, downloaded as they are
needed and then kept on disk. They need a free account.

1. Register at [urs.earthdata.nasa.gov](https://urs.earthdata.nasa.gov).
2. Sign in, open **Generate Token**, and generate one.
3. Create a file named `.env` beside `FlightPlannerApp.exe`, holding:

   ```
   EARTHDATA_BEARER_TOKEN=<your token>
   ```

The token is yours alone — don't share it. It expires after about 60 days; put a reminder
in your diary. When it lapses, downloads stop, the log says "Earthdata authentication
failed … check EARTHDATA_BEARER_TOKEN", and only tiles already on disk are used. Generate a
new token and replace the value. If a fresh token still fails, check in your Earthdata
profile that the LP DAAC data applications are authorised.

The base maps and the 3D terrain need no account or key.

## Folders

`.env` can also set where the app works. All four lines are optional; these are the
defaults. Use single quotes so the backslashes survive.

```
DEM_DIR='c:\temp\dem'
TASK_DIR='c:\temp\task'
LOG_DIR='c:\temp\log'
OUT_DIR='c:\temp\out'
```

| Folder | Holds | Created by |
|---|---|---|
| `c:\temp\dem` | SRTM elevation tiles, downloaded once each | The app |
| `c:\temp\task` | One folder per task — see below | **You** — it must exist |
| `c:\temp\log` | `logYYYYMMDD.txt`, one per day | The app |
| `c:\temp\out` | GeoJSON, CSV and JSON the app writes | The app |

Your settings (resolution, MacCready and so on) are kept in
`%LOCALAPPDATA%\FlightPlanner\settings.json`; delete it to go back to the defaults.

A task folder holds the task and whatever goes with it:

```
c:\temp\task\Yosemite\
    SSC US Mammoth Yosemite 238.pln              the task        (File ▸ Load Task Plan)
    SSC 311 High Cu T10-14 SW15 - 24v2.WPR       weather preset  (asked for at task setup)
    SSC US Mammoth Yosemite 238_plan_route.json  a saved plan    (optional)
    *.igc / *.csv                                pilots' flights (optional)
```

## Using it

- **File ▸ Load Task Plan** opens a task's `.pln`. Task setup follows: the weather preset
  (`.WPR`, from the task's folder), the glider, the plan's resolution and MacCready.
- **File ▸ Route ▸ Plan Route** plans it. The line is coloured by what the glider is doing
  — ridge green, glide red, sink orange, climbs purple dots — and each node carries a card:
  the height there, how to reach it and what follows.
- **File ▸ Route ▸ Show Plan Summary** and **Show Profile** give the summary and the height
  over the ground along a leg.
- **File ▸ Route ▸ Save Route / Load Route** keep a plan.
- If the plan misses a line you wanted, **Ctrl + click** along it on the map to draw a guide
  line and plan again; the route then follows it. Guide lines are saved with the plan.
- **File ▸ Load IGC** draws a pilot's flight.

On the map: a click shows the ground height under the pointer. **N / T** switch north-up
and track-up, **C** centres on the glider, **R** clears the vario trail. Without the sim,
**Shift + click** drops a what-if glider and every route line then shows the height above
ground it would arrive with. **Connect** links to MSFS 2024.

[**Route planning — a quick guide**](RoutePlanning-UserGuide.md) covers planning properly,
including guide lines and how to read the result. The
[**Dictionary**](Dictionary.md) explains the terms used on screen.

## Does it work? A first run check

1. The map shows when the app opens.
2. **File ▸ Load Task Plan** on an area you have not used before: files appear under
   `c:\temp\dem` and the log shows them downloading. Earthdata is working.
3. Press **3D**: the terrain rises. The terrain tiles are reachable.
4. With MSFS 2024 running in Developer Mode, **Connect**: the glider appears on the map.

| Symptom | Likely cause |
|---|---|
| "Earthdata authentication failed" in the log | Token missing or expired — generate a new one |
| Planning works on old areas but not new ones | The same: no new tiles can be downloaded |
| "3D terrain tiles … cannot be reached" | No internet, or the terrain tile service is down |
| Blank map | The app could not reach the base map tiles; check the log |
| The sim never connects | MSFS 2024 is not in Developer Mode |

## Developer mode

Some menus and controls are development tools and are hidden: **File ▸ Ranked Ridges**, the
**Manual Ridge** menu, the **Ridge** button and the vario slider. To show them, add this
line to `.env` and restart:

```
DEV_MODE=true
```

## Reporting a problem

Please include the version, what you were doing, and the day's log from `c:\temp\log`. The
log holds no personal data, but it does name your task folders.
